# Computer Networking Lab

This repository contains Python programs developed for the Computer Networking Lab assignments.

## Experiment 1: Client-Server Communication

A simple TCP client-server program using Python socket programming.

The client sends a text message to the server, and the server receives the message and sends an acknowledgment.

### Files
- `server.py` - Server-side program
- `client.py` - Client-side program

## Experiment 2: Network Device Classification

A Python program that classifies network devices and transmission media according to their OSI layer and primary function.

### Devices and Media Covered
- Switch
- Router
- Bridge
- Access Point
- Twisted Pair Cable
- Coaxial Cable
- Fiber Optic Cable
- Wireless

### File
- `network_classification.py` - Classification program

The complete typed PDF report containing the aim, theory, working procedure, source code, outputs, and results is included in the `Report` folder.
